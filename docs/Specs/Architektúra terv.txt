ARCHITEKTÚRA TERV
=================

Tervezési szempontok:

 - Rugalmasan bővíthető, skálázható rendszer:
 	Microservice arhitectúra: .Net Core C# backend
	
 - Minimális késleltetésű (real-time) jelfeldolgozás, Dinamikus Adatáramlás (Data Flow):
	MessageQueue használata: RabbitMQ + Topic Exchange
	
 - Gyors adatbázis kezelés:
	PostgreSQL - JSON formátumú mezők jobb (és gyorsabb) kezelése miatt
	Cache Startegy - Ha a későbbiekben szükséges lenne az adatbázis kezelés gyorsítása
